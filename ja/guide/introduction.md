# はじめに

## Ordo とは？

Ordo は Rust で書かれた C/C++ 向けのビルド・プロジェクト管理ツールです。プロジェクトの作成から依存管理、ビルド、実行まで、Cargo のような開発体験をひとつの CLI で提供します。

現代の C/C++ 開発では、複数のツールを使い分ける必要があります。

- **CMake** — ビルド設定
- **Ninja** — ビルド実行
- **vcpkg** や **Conan** — パッケージ管理
- **pkg-config** — システムライブラリの検出
- **clang-format** や **clang-tidy** — コード品質管理

Ordo はこれらをひとつのワークフローに統合します。`CMakeLists.txt` を書いたり、ツールチェインファイルを設定したり、パッケージマネージャーを手動で接続したりする代わりに、`Ordo.toml` を書くだけで残りは Ordo が処理します。

```sh
ordo new myapp
cd myapp
ordo add vcpkg:fmt@11.2.0
ordo build
ordo run
```

## 設計思想

> **エコシステムを置き換えるのではなく、オーケストレーションする。**

Ordo はコンパイラ、リンカ、パッケージマネージャーを再実装しません。既存のツール群 — ビルドには Ninja、依存管理には vcpkg/Conan/pkg-config、コンパイルには Clang/GCC/MSVC — を、一貫性のある使いやすいインターフェースの背後で協調させます。

## 主な機能

- **Cargo ライクな CLI** — `new`, `build`, `run`, `add`, `update`, `tree`, `clean`
- **統一された依存管理** — vcpkg、Conan、pkg-config、system、git の 5 つのプロバイダをひとつのインターフェースで利用可能
- **Ninja 直接生成** — パイプラインに CMake は不要
- **再現性のあるビルド** — `Ordo.lock` によるインテグリティハッシュ付きのロックファイル
- **ワークスペース対応** — モノレポをネイティブにサポートし、依存とツールチェインを共有
- **Lua ビルドスクリプト** — git 依存のビルド用サンドボックススクリプト
- **ツールチェイン自動検出** — Clang、GCC、MSVC
- **IDE 連携** — `compile_commands.json` を自動生成

## 仕組み

Ordo は `Ordo.toml` マニフェストを読み込み、設定されたプロバイダを通じて依存を解決し、`build.ninja` ファイルを直接生成します。その後 Ninja がビルドを実行します。

```
Ordo.toml → Ordo (依存解決, ninja 生成) → build.ninja → Ninja → バイナリ
```

中間の CMake ステップはありません。ビルドパイプラインはシンプルで透過的です。問題が発生した場合も、どこを調べればよいかがすぐにわかります。

## 現在のステータス

Ordo は活発に開発中です。プロジェクト作成、依存管理、ビルド、実行といったコアワークフローは動作しています。最新の更新情報については [Changelog](/ja/changelog) をご覧ください。
