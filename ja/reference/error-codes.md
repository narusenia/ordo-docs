# エラーコード

Ordoは構造化されたエラーコードを使って問題の特定と解決を支援します。各コードは接頭辞によってドメインが示されます。

## E00xx — 設定

`Ordo.toml` のパースと設定解決に関するエラーです。

| コード | 説明 |
|------|------|
| `E0001` | `Ordo.toml` の読み込みに失敗しました。ファイルが存在しないか、アクセスできない可能性があります。 |
| `E0002` | TOMLパースエラー。マニフェストに無効なTOML構文が含まれています。 |
| `E0003` | マニフェスト検証エラー。TOMLとしては有効ですが、フィールドが不正または不足しています（例: `[package].name` がない）。 |
| `E0004` | 設定解決エラー。設定階層（CLI、環境変数、プロジェクト、ワークスペース、グローバル）間で矛盾する設定があります。 |

## E01xx — 依存関係解決

依存関係の解決とロックファイル操作に関するエラーです。

| コード | 説明 |
|------|------|
| `E0100` | 依存関係が見つかりません。指定されたパッケージが設定済みプロバイダに存在しません。 |
| `E0101` | バージョン競合。2つ以上のパッケージが共有依存関係の互換性のないバージョンを要求しています。 |
| `E0102` | プロバイダ未指定。依存関係の宣言が曖昧です。`provider` フィールドを指定するか、`ordo add` でプロバイダ接頭辞を使ってください。 |
| `E0103` | ロックファイルの不整合。`Ordo.lock` が現在の `Ordo.toml` と一致しません。`ordo update` で再解決するか、`--locked` を外してください。 |
| `E0104` | ハッシュ不一致。`Ordo.lock` のチェックサムがダウンロードされた成果物と一致しません。ダウンロードの破損またはパッケージの改ざんの可能性があります。 |

## E02xx — ビルド

ビルドプロセスに関するエラーです。

| コード | 説明 |
|------|------|
| `E0200` | Ninjaが見つかりません。[Ninja](https://ninja-build.org/) をインストールし、`PATH` に含まれていることを確認してください。 |
| `E0201` | コンパイル失敗。1つ以上のソースファイルのコンパイルに失敗しました。上のコンパイラ出力を確認してください。 |
| `E0202` | リンク失敗。リンカが最終バイナリを生成できませんでした。よくある原因はライブラリの不足、未定義シンボル、互換性のないオブジェクトファイルです。 |
| `E0203` | ビルド成果物が見つかりません。Ninjaの実行は成功しましたが、期待される出力ファイルが生成されませんでした。 |

## E03xx — ツールチェイン

コンパイラとツールチェインの検出に関するエラーです。

| コード | 説明 |
|------|------|
| `E0300` | コンパイラが見つかりません。OrdoはC/C++コンパイラを検出できませんでした。Clang、GCC、またはMSVCをインストールしてください。 |
| `E0301` | コンパイラのバージョンが古すぎます。検出されたコンパイラは要求された言語標準をサポートしていません。 |
| `E0302` | 未サポートのターゲットトリプル。指定された `--target` が認識されないか、必要なクロスコンパイルツールチェインがインストールされていません。 |
| `E0303` | sysrootが見つかりません。`[target.<triple>]` で指定された `sysroot` パスが存在しません。 |

## E04xx — テスト

テスト実行に関するエラーです。

| コード | 説明 |
|------|------|
| `E0400` | テストバイナリのビルドに失敗しました。テストソースのコンパイルに失敗しました。 |
| `E0401` | テスト実行に失敗しました。1つ以上のテストが非ゼロの終了コードを返しました。 |
| `E0402` | テストが見つかりません。設定されたテストディレクトリにテストソースが見つかりませんでした。 |
